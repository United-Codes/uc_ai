UC AI is a PL/SQL framework that turns your Oracle database into the runtime for AI agents. An agent reasons about a task, calls your own PL/SQL functions to read and change data, remembers what it learned, and hands work to other agents. You need no Python, no middle tier, and no external orchestrator.

<Aside type="tip" title="New to UC AI?">
See [**what you can build**](/products/uc-ai/docs/guides/use-cases/) — ticket triage, document Q&A, in-database chatbots, and more — or jump straight to the [**Quickstart**](/products/uc-ai/docs/guides/quickstart/).
</Aside>

## Follow one request through a team of AI agents

A customer says they were charged twice. One question goes in, and a coordinator hands it to the specialists who can answer it.

<AgentFlow client:visible />

This is a multi-agent system: specialist agents work together on one request. With UC AI, you build these agents in PL/SQL.

<LinkButton href="/products/uc-ai/docs/tutorial/build-an-agent/01-the-scenario/" icon="right-arrow">
  Build your first agent
</LinkButton>

<details>
<summary>How UC AI runs this</summary>

You define each agent and the tools it may use. The orchestrator asks an AI model which specialist to call. UC AI runs that specialist and returns its result.

A specialist asks the model which of its tools to call, and UC AI runs that tool as your PL/SQL function. The function runs SQL against your own tables, so reading your data never leaves the database. The agent then asks the model again with the rows it received. Each agent is its own loop, so one request makes several model calls. An agent can hold more tools than one run needs, and the model chooses between them.

One session groups the whole run, so you can see every agent, every tool call, and every token it used. Each agent can use its own model.

Model requests can include prompts and tool results. Your model configuration determines where those requests go.

</details>

## Perfect for Oracle Developers

This framework is specifically designed for Oracle Database developers who want to:

- **Build agents in PL/SQL**: Write the agent, its tools, and its prompts as database objects
- **Automate Tasks**: Let AI models call your functions from a natural language prompt
- **Keep data in place**: Tools read your own tables, with no copy to a middle tier
- **Extend Functionality**: Give AI models access to custom business logic and database operations
- **Maintain Control**: Keep AI interactions secure with validated parameters, budgets, and controlled execution

## Quick Example

<Tabs>
<TabItem label="One AI call">

```sql
DECLARE
  l_result JSON_OBJECT_T;
BEGIN
  -- Let AI answer a question using a custom tool
  l_result := uc_ai.generate_text(
    p_user_prompt => 'How many open tickets do I have?',
    p_system_prompt => 'You are a helpful assistant to an ticketing system.
    Use the provided tools to access the database.
    You are currently talking to the user "John Doe"',
    p_provider => uc_ai.c_provider_openai,
    p_model => uc_ai_openai.c_model_gpt_5_6_luna
  );

  -- Get the AI's response
  DBMS_OUTPUT.PUT_LINE('AI Response: ' || l_result.get_string('final_message'));
  -- You have 5 open tickets.
END;
/
```

</TabItem>
<TabItem label="A multi-agent run">

```sql
DECLARE
  l_result     JSON_OBJECT_T;
  l_session_id VARCHAR2(100);
BEGIN
  -- One session groups every agent, tool call, and token count of the run
  l_session_id := uc_ai_agents_api.generate_session_id;

  -- The orchestrator decides which specialist agents to call
  l_result := uc_ai_agents_api.execute_agent(
    p_agent_code       => 'support_orchestrator',
    p_input_parameters => JSON_OBJECT_T(
      '{"prompt": "Customer 4711 says invoice INV-1003 was charged twice."}'
    ),
    p_session_id       => l_session_id
  );

  DBMS_OUTPUT.PUT_LINE(l_result.get_clob('final_message'));
END;
/
```

See the [multi-agent systems guide](/products/uc-ai/docs/guides/multi-agent-systems/) for the agents behind this call.

</TabItem>

## Supported AI Providers

- **OpenAI**: GPT-5.6 Sol / Terra / Luna, GPT-5.5, the GPT-5.4 family, and text-embedding-3...
- **Anthropic**: Claude Fable 5, Claude Opus 5, Claude Sonnet 5, Claude Haiku 4.5, and the Claude 4.x family...
- **Google**: Gemini 3.7 Flash, Gemini 3.1 Pro, Gemini 3.5 Flash / Flash-Lite, plus Gemini embeddings...
- **xAI**: Grok 4.6, Grok 4.5, Grok 4.3, Grok 4.20, Grok Build...
- **Mistral**: Mistral Large / Medium / Small, Ministral, Codestral...
- **Ollama**: Local LLMs like Llama, Qwen, Gemma, GPT-OSS, and more
- **OCI**: Oracle Cloud Infrastructure Generative AI — Llama 4, Cohere Command A, Gemini 2.5, Grok 4.3, GPT-OSS...
- **OpenRouter**: Unified API for 300+ models from OpenAI, Anthropic, Google, Meta, Mistral, and more
