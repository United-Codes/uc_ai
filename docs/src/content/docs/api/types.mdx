## Language Model Type Definitions

Inspired by [Vercels AI SDK](https://v5.ai-sdk.dev/providers/community-providers/custom-providers#languagemodelv2).

### Language Model Prompt

Conversations with LLMs consist of a series of prompts/messages. Each prompt can be of four types:

- **system**: Provides context or instructions to the model.
- **user**: Represents the user's input or question.
- **assistant**: Represents the model's response.
- **tool**: Represents a tool call made by the model.

Check the next section for the structure of each type.

```json
// system
{
  "role": "system",
  "content": string
}
// user
{
  "role": "user",
  "content": [LanguageModelText | LanguageModelFile]
}
// assistant
{
  "role": "assistant",
  "content": [LanguageModelText | LanguageModelFile | LanguageModelReasoning | LanguageModelToolCall]
}
// tool
{
  "role": "tool",
  "content": [LanguageModelToolResult]
}
```

### Language Model Content

#### Language Model Text

```json
{
  "type": "text",
  "text": string,
  "providerOptions": object // Optional provider-specific options
}
```

#### Language Model File

```json
{
  "type": "file",
  "mediaType": string, // IANA media type (e.g., 'image/png', 'audio/mp3')
  "data": string, // file content encoded in base64
  "filename?": string, // Optional filename for the file
  "providerOptions": object // Optional provider-specific options
}
```

#### Language Model Reasoning

```json
{
  "type": "reasoning",
  "text": string,
  "providerOptions": object // Optional provider-specific options
}
```

#### Language Model Tool Call

```json
{
  "type": "tool_call",
  "toolCallId": string,
  "toolName": string,
  "args": string, // JSON string of arguments passed to the tool
  "providerOptions" object // Optional provider-specific options
}
```

#### Language Model Tool Result

```json
{
  "type": "tool_result",
  "toolCallId": string,
  "toolName": string,
  "result": string, // JSON string of the tool result
  "providerOptions" object // Optional provider-specific options
}
```

## Decision Type Definitions

The types of `uc_ai.decide`. See [Decide](/products/uc-ai/docs/api/decide/) for the rules and for examples.

### Decision Question

`p_questions` is an object. Each key is a question id (`^[A-Za-z][A-Za-z0-9_]{0,63}$`).

```json
{
  "<id>": {
    "type": "boolean" | "choice" | "score",
    "instructions": string,
    "criteria": object | array // choice: {option: description}, score: [description], boolean: {"true": string, "false": string}
  }
}
```

### Decision Answer

```json
// boolean
{ "type": "boolean", "probability": number }
// choice
{ "type": "choice", "choice": string, "probabilities": { "<option>": number } }
// score. The keys of probabilities are the level indexes as strings
{ "type": "score", "score": number, "probabilities": { "0": number } }
// refused (OpenAI only)
{ "type": "refused" }
```

### Decision Result

```json
{
  "answers": { "<id>": DecisionAnswer },
  "usage": { "input_tokens": number, "output_tokens": number, "total_tokens": number }, // only reported keys
  "model": string,
  "provider_metadata": { "confidence": { "<id>": number }, "usage": object },
  "warnings": [string],
  "raw": object // the response of the provider
}
```
